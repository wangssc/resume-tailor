# HR 四项打分细则

每份简历交付前给一张表，四项各 100 分，**每项一句话客观理由**。不画饼、不讨好、不堆形容词。

## 1. 网申通过率（会不会被筛掉）

| 看什么 | 加分 | 扣分 |
|---|---|---|
| ATS 关键词 | JD 里的硬技能词、行业词命中原词 | 关键词全靠近义词、命中率为零 |
| 硬门槛 | 学历、专业、届别、语言成绩全部满足 | 专业不符 / 学历不符 / 届别不符 / 语言不达标（一票否决项） |
| 经历 | 有同行业、同职能的实际经历 | 只有校园经历，且与岗位无关 |
| 加分项 | 竞赛、证书、作品、开源 | 无任何可验证产出 |

## 2. 最终上岸率（投了能不能拿到 offer）

三件事相乘：**竞争烈度 × 简历竞争力 × 应届生面试平均水平**。
- 竞争烈度：招几人、投递量级、是否名企（一人岗哪怕是普通公司也很难）
- 简历竞争力：与岗位的贴合度、有无硬缺口
- 面试水平：应届生普遍在行为面崩，无相关经历的候选人尤甚

结论要给区间（如「10-15%」）并说明主要影响因子，不要给「很大」「较高」这种空话。

## 3. 行业发展前景分

- 赛道增速：行业是在扩张、持平还是收缩
- 需求稳定性：岗位是刚需职能还是项目制、外包制
- 长期天花板：3-5 年后能到什么位置，是否可迁移

## 4. 岗位幸福度分

- 工作强度与加班：日常工时、是否轮班、出差比例
- 薪资性价比：起薪在同城同岗中的位置，涨幅节奏
- 职场压力与倦怠风险：KPI 强度、汇报关系复杂度、可替代性

**利弊都要写**。高分不给满分，低分要说清「低在哪、能不能忍」。

## 5. 均分定级

| 等级 | 条件 | 含义 |
|---|---|---|
| **S** | 均分 ≥ 71，或匹配度为当前所有岗位最高 | 强烈推荐，优先投 |
| **A** | 68-70 | 推荐冲刺，主投方向 |
| **B** | 60-67 | 稳妥保底 |
| **C** | < 60，或存在不可补的硬缺口 / 真实性风险 | 不建议 |

## 6. 输出模板

```
| 维度 | 分数 | 理由（一句话） |
|---|---|---|
| 网申通过率 | 72 | 专业与关键词全命中，但无相关实习，筛简历阶段不吃亏、进面后偏弱 |
| 最终上岸率 | 60 | 招 2 人收到量级偏大，简历中等，主要靠面试翻盘 |
| 行业发展前景 | 78 | 赛道仍在扩张，岗位是刚需职能，天花板中等 |
| 岗位幸福度 | 65 | 起薪中上但加班常态，适合 2-3 年攒经验 |

综合均分 68.75 → **A（推荐冲刺）**
```
